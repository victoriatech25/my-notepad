## 1. 화면 배치

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 메뉴바: 파일 편집 검색 보기 인코딩 도움말 (프로토타입)                │
├──────────────────────────────────────────────────────────────────────┤
│ 탭 바: [README.md] [회의록.txt ●] [Untitled-1] …  ＋   [소스|분할|미리보기] │
├──────────┬───────────────────────────────────────────────────────────┤
│ 사이드바  │ 찾기/바꾸기 바 (Ctrl+F / Ctrl+H 때만 표시)                 │
│ (폴더    ├───────────────────────────────────────────────────────────┤
│  트리)   │  줄 │ 에디터 본문                    ┊ (분할 시) 미리보기     │
│          │  번 │                                ┊                       │
│  Ctrl+B  │  호 │                                ┊                       │
├──────────┴───────────────────────────────────────────────────────────┤
│ 상태 표시줄: Ln 12, Col 5 · 선택 3자 · 120줄 │ 100% │ LF │ UTF-8      │
└──────────────────────────────────────────────────────────────────────┘
```

| 영역 | 결정(초안) | 근거 |
| :--- | :--- | :--- |
| 메뉴바 | 최상단: 파일 · 편집 · 검색 · 보기 · 인코딩 · **창** · 도움말. 항목 옆에 OS별 단축키 표기 | 기능 발견성. `창` 메뉴는 UX-003 ([스크린샷](screens/p0-ux2-window-menu.png)) |
| 탭 바 | 메뉴 아래 한 줄 유지. 넘치면 가로 스크롤 + 양 끝 `‹ ›` 버튼(넘칠 때만) + 마우스 휠 가로 스크롤, 선택 탭 자동 스크롤, 오른쪽 고정 `＋`(새 탭)·`⌄`(열린 탭 목록·검색). 우측 끝에 Markdown 보기 모드 토글(`.md` 탭에서만) (UX-002, [전](screens/p0-ux2-tabs-overflow-before.png)·[후](screens/p0-ux2-tabs-overflow-after.png)) | 탭은 문서 단위, 보기 모드도 탭 단위 상태 |
| 사이드바 | 좌측, 기본 폭 220px, 드래그로 조절. 닫기: 머리글 `«` 버튼 · `Ctrl+B` · 보기 메뉴. 닫힌 상태에서는 폭 30px 세로 띠(`»`, 띠 전체 클릭 가능)로 다시 열기 (UX-001) | Notepad++/VS Code 관례 |
| 찾기/바꾸기 바 | **에디터 상단**(탭 바 아래)에 펼쳐짐, 바꾸기는 두 번째 줄 | 본문 시선 흐름과 가까움 |
| 줄 번호 | 에디터 좌측, 현재 줄 번호 강조 | |
| 상태 표시줄 | 좌: 커서·선택·줄 수 / 우: 확대율·줄바꿈·인코딩 (클릭 시 팝업) | 우측은 "바꿀 수 있는 값" 묶음 |

## 2. 색상 토큰 (초안)

## 3. 대화상자 문구 (초안)

| 상황 | 제목 | 본문 | 버튼 (기본 버튼 굵게) |
| :--- | :--- | :--- | :--- |
| 미저장 닫기 | 변경 내용을 저장할까요? | "회의록.txt"의 변경 내용이 저장되지 않았습니다. | **저장** · 저장 안 함 · 취소 |
| 표현 불가 문자 | EUC-KR로 저장할 수 없는 문자가 있습니다 | 아래 문자는 EUC-KR (CP949)에 없습니다. 그대로 저장하면 `?`로 바뀝니다. (문자·위치 목록) | **UTF-8로 저장** · `?`로 바꿔 저장 · 취소 |
| 외부 변경 | 파일이 다른 프로그램에서 변경되었습니다 | "server.log"가 디스크에서 변경되었습니다. 다시 불러올까요? (편집 중이면: 내 변경 내용은 사라집니다) | **다시 불러오기** · 내 버전 유지 |
| 바이너리 | 텍스트 파일이 아닌 것 같습니다 | "image.dat"에 텍스트가 아닌 데이터가 있습니다. 열면 내용이 깨져 보이고, 저장하면 파일이 손상될 수 있습니다. | 읽기 전용으로 열기 · **취소** |
| 대용량 (1~5MB 상단 안내 막대) | (대화상자 아님 — 에디터 상단 배너) | 큰 파일이라 입력이 느릴 수 있습니다 | **읽기 전용으로 보기** · 닫기(`×`) |
| 대용량 (5MB 초과 편집 전환 경고) | 큰 파일을 편집 모드로 열까요? | "huge.log" (85MB)는 권장 편집 크기(5MB)를 넘습니다. 편집 모드로 열면 입력과 화면 반응이 느려지거나 메모리를 많이 쓸 수 있습니다. | 편집 모드로 열기 · **읽기 전용 유지** |

## 5. UX-1에서 확인한 질문 (결정 완료)

- 찾기/바꾸기 바 위치 → **에디터 상단** (UX-1 승인)
- Markdown 보기 모드 토글 위치 → **탭 바 우측** (UX-1 승인)
- ~~탭이 많을 때: 가로 스크롤 vs 여러 줄 vs 목록 드롭다운~~ → **결정: 한 줄 + `‹ ›`·휠 스크롤 + 선택 탭 자동 스크롤 + `⌄` 목록 (UX-002)**
- 사이드바 파일 열기 → **한 번 클릭** (UX-1 승인)
- `.md` 기본 보기 모드 → **분할** (UX-1 승인)

## 6. 파일·폴더 아이콘 (P0-UX2 결정)

PLAN.md §3.1-3 기준. 사이드바와 탭 바에 같은 아이콘을 쓴다.

| 항목 | 내용 |
| :--- | :--- |
| 결정 순서 | 파일 이름 정확히 일치 → 확장자 → 기본 아이콘 |
| 폴더 | 이름별 아이콘 + 열림/닫힘 구분 |
| `.gitignore` 대상 | 숨기지 않고 흐리게 표시 |
| 방식 | **A. 단색 아이콘 폰트 Phosphor + 파일 종류별 색 (채택, 2026-10-20)** — 시안 [p0-ux2-icons-a-font.png](screens/p0-ux2-icons-a-font.png). B안(Material 다색 SVG)은 비교 후 제외, 설정 전환 없음 |
| 용량 | 실행 파일 약 +0.47MB (폰트 내장) |
| 첫 시안 대상 | `.rs`, `.md`, `.toml`, `.json`, `.txt`, `.log`, `.exe`, `Cargo.toml`, `Cargo.lock`, `.gitignore`, `README.md`, 폴더 `src`·`docs`·`tests`·`target`·`.cargo` |
