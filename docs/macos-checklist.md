### 3-1 줄 번호 Gutter·자동 줄바꿈 (P2-01)
```bash

```
- [x] **3-1a** `lines-12k.txt`를 트랙패드로 끝까지 스크롤해도 줄 번호와 본문 줄이 어긋나지 않고, 번호 칸이 5자리로 넓다
- [x] **3-1b** 줄 번호 칸 배경이 본문과 구분되고(라이트 `#E8E8E8`, 다크 `#2C2C2C`), 현재 줄 번호가 진하게 보인다
- [x] **3-1c** `long-lines.txt`에서 보기 → 자동 줄바꿈 켬: 긴 줄(3·8·13번…)이 접혀 보이고 접힌 행에는 번호가 없다

### 3-2 확대/축소·줄 이동·탭 너비 (P2-02)
```bash
cargo xtask try tabs        # 12,000줄 + 탭 들여쓰기 문서
```
- [x] **3-2a** `Cmd+=`(또는 `Cmd++`) / `Cmd+-` / `Cmd+0`으로 **본문 글꼴만** 커지고 작아지고 원래대로 돌아온다 (메뉴·탭 바 등 화면 전체가 커지면 ❌). 줄 번호도 함께 바뀌고 상태 표시줄 %가 바뀐다
- [x] **3-2b** `Cmd+L`(줄 이동) → `6000` → `Enter`: 그 줄로 커서가 가고 화면 가운데에 온다. `99999`는 대화상자 안에 빨간 안내가 뜨고 닫히지 않는다. `Esc`로 닫힌다
- [x] **3-2c** 탭 문서에서 보기 → 탭 너비 2/4/8칸: 들여쓰기 폭이 바로 바뀐다. "Tab 키로 공백 넣기"를 켜고 `Tab`을 누르면 공백이 들어간다

### 3-4 폴더 탐색 사이드바 (P2-05·P2-06)
```bash
cargo xtask try sidebar     # 이 저장소 폴더를 사이드바로 연다
```
- [x] **3-4a** 트리가 보이고 `Cmd+B`로 접기/펴기, 머리글 `«`로 닫고 왼쪽 띠 `»`(띠 어디든)로 다시 연다. 폭을 바꾼 뒤 닫았다 열어도 폭이 유지된다
- [x] **3-4b** 폴더 한 번 클릭으로 펼침/접힘, 파일 한 번 클릭으로 탭에서 열림 (이미 열린 파일은 그 탭으로 이동), 현재 탭 파일이 트리에서 선택 색
- [x] **3-4c** `.git`·`.DS_Store`가 보이지 않고, `target`이 흐리게 보인다 (펼쳐도 멈춤 없음)
- [x] **3-4d** 아이콘: `.rs`·`.md`·`.toml`·`Cargo.toml`·`.gitignore`·`README.md`가 종류별 아이콘·색, 폴더는 펼치면 열린 폴더 아이콘. Retina에서 선명하다. 탭 바에도 같은 아이콘
- [x] **3-4e** `파일 → 폴더 열기…`로 macOS 폴더 선택 창이 뜨고 고른 폴더가 열린다. Finder에서 폴더를 앱 창에 끌어다 놓아도 사이드바에 열린다
- [x] **3-4f** 터미널에서 `touch ~/devel/my-notepad/zz-new.txt` 후 사이드바 `⟳` → 새 파일이 나타난다 (확인 후 `rm ~/devel/my-notepad/zz-new.txt`)
- [x] **3-4g** (선택) 순환 링크: `mkdir -p /tmp/loop-test/a && ln -s /tmp/loop-test /tmp/loop-test/a/back` → 사이드바로 `/tmp/loop-test`를 열고 `a` → `back`을 펼치면 펼쳐지지 않고 `⚠`(마우스를 올리면 "순환하는 링크") 표시

- [x] **5-1e 🍎** 찾기 입력란에 **한글 2벌식**으로 `검색`을 입력할 때 조합이 깨지지 않고, 조합이 끝나면 결과가 맞다 (`\b` 끄면 15개, 켜면 7개)
- [x] **5-1f** `Esc`로 닫으면 강조가 사라지고 커서는 마지막 매치에 남는다 (에디터를 누른 뒤 `Esc`로도 닫힌다)

### 5-2 바꾸기 (P4-02·P4-05) — `search_ko.txt` 7번
- [x] **5-2a 🍎** `Cmd+Option+F`로 찾기 줄 아래에 바꾸기 줄이 열린다 (찾기 줄 맨 앞 `▸`로도 펼침, `Cmd+F`는 바꾸기 줄을 접는다)
- [x] **5-2b** `바꾸기`는 현재 매치만 바꾸고 다음 매치로 간다 (선택이 매치가 아니면 바꾸지 않고 다음 매치로만)
- [x] **5-2c** `모두 바꾸기` 후 "N개 바꿈"이 보이고, `Cmd+Z` **한 번**으로 전부 되돌아간다. 바꾸기 입력란에서 `Cmd+Option+Enter`도 모두 바꾸기
- [x] **5-2d** `.*`를 켜고 찾기 `(\d+)-(\d+)` · 바꾸기 `$2-$1` → `범위 10-20, 3-4, 100-200` 줄이 `20-10, 4-3, 200-100`이 된다
- [x] **5-2e** 바꾸기 입력란에 한글을 2벌식으로 입력할 수 있고, 찾기·바꾸기 입력란에서 `Cmd+Z`를 눌러도 문서는 되돌아가지 않는다

- [x] **5-3b** 검색어를 빠르게 바꿔 입력해도 이전 검색어의 강조·개수가 남지 않고, 마지막 검색어 결과만 보인다. 뷰어에서도 매치 강조와 `Cmd+G` 이동이 된다 (바꾸기 버튼은 꺼짐)
